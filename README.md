# 🎙️ Podcast Player 101
Bu proje, SQLite ve PHP tabanlı dinamik bir podcast yönetim ve oynatma sistemidir.

## Özellikler
- 🗄️ **SQLite** ile hafif ve hızlı veritabanı yönetimi.
- ⚡ **Vanilla JS** ile dinamik bölüm yükleme.
- 🎵 **HTML5 Audio API** ile sorunsuz oynatma/durdurma.
- 📱 Responsive tasarım (Mobil uyumlu).

## Kurulum
1. Dosyaları AMPPS/XAMPP `www` klasörüne atın.
2. `localhost/proje_adi/database.php` dosyasını çalıştırarak veritabanını oluşturun.
3. Ana sayfayı açın ve dinlemeye başlayın!# Podcast-Haberin-Var-M-Website-
